# Personal Portfolio Website

A simple personal portfolio website created using HTML as part of my web development learning journey.

## About the Project

This project represents my first step into practical web development. I created a personal portfolio to practice HTML concepts and understand how webpages are structured.

## Features

- Personal introduction
- Profile picture
- LinkedIn, GitHub and Instagram links
- About section
- Skills section
- Academic performance table
- Contact information

## Technologies Used

- HTML5

## What I Learned

- HTML document structure
- Headings and paragraphs
- Images and hyperlinks
- Lists and tables
- Semantic HTML elements
- Basic inline styling

## Future Improvements
